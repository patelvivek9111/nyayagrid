# Production Readiness — NyayaGrid (Phase 9)

This is an honest, as-of-today checklist of what must be true before NyayaGrid serves real client
matters. It intentionally does not sugar-coat gaps. Every row is one of:

- **READY** — implemented, verified, safe to run in production as configured.
- **CONFIG REQUIRED** — the code exists and works; an operator must supply real
  credentials/infrastructure before go-live (the app already refuses to boot in production without
  it — see [Production configuration gate](#production-configuration-gate)).
- **BLOCKER** — no adapter/process exists yet, or the control has never been exercised end to end.
  Must be built or completed before production launch.
- **OPTIONAL** — a real improvement, but not required to launch safely.

This document is Phase 9 output, not a "Phase complete" declaration. Do not read this file as a
sign-off; a human (engineering + legal) must review it before any production deployment.

## Production configuration gate

`packages/platform/src/config.ts` is the single source of truth for "is this configuration safe to
run in production." `validateConfigForEnv()` runs once per server process
(`apps/web/src/instrumentation.ts`) and:

- **Refuses to start** (throws `ConfigurationError`) when `APP_ENV=production` and any item below
  is unmet.
- **Logs every item as a warning** (without refusing to start) when `APP_ENV=staging`, so a
  rehearsal deployment surfaces every gap without being unbootable.
- Is silent (besides a "development stand-ins active" log line) in `development`/`test`, because
  those environments are _supposed_ to run mocks.

`GET /api/health/ready` exposes the same summary (provider names and booleans only — never a
secret) so this can be checked from outside the process too.

| #   | Item                                                                                | Status                    | Notes                                                                                                                                                                                                                                                                                                                                                                     |
| --- | ----------------------------------------------------------------------------------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| 3   | `AI_PROVIDER=openai` with `OPENAI_API_KEY`                                          | CONFIG REQUIRED           | `MockAIProvider` returns fixture text and must not answer legal questions.                                                                                                                                                                                                                                                                                                |
| 4   | `EMBEDDING_PROVIDER=openai`                                                         | CONFIG REQUIRED           | Deterministic hash embeddings (mock) retrieve nothing real; citations would be grounded in nothing.                                                                                                                                                                                                                                                                       |

| 6   | `STORAGE_PROVIDER=s3` with production AWS credentials/IAM role                      | CONFIG REQUIRED / BLOCKER | MinIO is allowed only with `ALLOW_MINIO_IN_PRODUCTION=1` and only if the operator self-hosts/backs it up. Real AWS S3 production credentials, bucket policy, encryption-at-rest, and versioning have **not been provisioned** — BLOCKER until they are.                                                                                                                   |
| 7   | `OCR_PROVIDER` = a real adapter                                                     | BLOCKER                   | Only `none` is implemented today. Do not scale beyond one web instance until this exists, or accept that rate limits are per-instance.                                                           |

## Summary

**NyayaGrid is not production-ready today.** The application code enforces its own safety net (it
will not boot as `APP_ENV=production` with unsafe defaults), and the core product logic
(authorization, tenant isolation, capability gating, prompt-injection resistance, citation
grounding) is implemented and tested. What remains is almost entirely **external
infrastructure/verification work** — provisioning real providers (Clerk, OpenAI, ClamAV, AWS S3,
SMTP, Redis, Inngest Cloud), rehearsing backup/restore, getting legal review of user-facing
documents, and building real monitoring — rather than missing application code.
